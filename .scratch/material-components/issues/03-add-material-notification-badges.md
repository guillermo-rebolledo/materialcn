# 03 — Add Material notification badges

**What to build:** Add Material notification badges that can communicate an unread state or count when overlaid on icons and navigation destinations.

**Blocked by:** 01 — Establish Badge/Chip compatibility.

**Status:** ready-for-agent

- [ ] Dot, small numeric, and large numeric badge variants match the design kit.
- [ ] Numeric badges define and demonstrate overflow behavior such as `99+`.
- [ ] A badge can be positioned over an arbitrary icon without depending on a navigation component.
- [ ] Decorative dots are hidden from assistive technology while meaningful counts expose an accessible value.
- [ ] Stories cover standalone geometry, icon placement, counts, overflow, and light/dark presentation.
- [ ] Typecheck, lint, browser tests, and the library build pass.
