# 06 — Add Material lists and list items

**What to build:** Add flexible Material lists whose items can present primary and supporting information, media, metadata, and controls with the density options defined by the kit.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] One-, two-, and three-line list items match Material geometry and typography.
- [ ] Default, `-2`, and `-4` density options are supported without changing content semantics.
- [ ] Leading icons, avatars, media, overlines, supporting text, and trailing controls compose through stable slots.
- [ ] Interactive items render the correct link or button semantics and remain keyboard accessible.
- [ ] Checkbox, radio, and switch examples use the repository's existing controls.
- [ ] Stories cover densities, content configurations, interaction states, and light/dark presentation.
- [ ] Typecheck, lint, browser tests, and the library build pass.
